# 🐱 Pixel — Reactive Desktop Cat

A tiny pixel cat that sits on top of your desktop and reacts to what you do.

## Run

```bash
npm install
npm start
```

Or make a no-terminal launcher: run `tools\install-shortcut.ps1` once, then
**double-click "Pixel Cat"** on your Desktop to turn it ON — **double-click again to
turn it OFF**. (`Ctrl+Alt+C` also hides/shows it; right-click the tray icon for size,
position, and quit.)

## What it does

| Your action         | The cat                              |
|---------------------|--------------------------------------|
| Move the mouse      | turns to face your cursor            |
| Type                | sits at a keyboard and taps the keys |
| Scroll              | plays with a bouncing ball of yarn 🧶 |
| Right-click         | startled jump                        |
| `Alt+F4` / `Ctrl+W` | sits up and waves `bye~`             |
| Open email          | meows with a letter ✉ + hearts       |
| Idle (~30s)         | lies down and sleeps `z z z`         |
| Left alone          | wanders, grooms, and meows on its own |
| Click the cat       | **pet** — meow + hearts 💕           |
| Spam-click the cat  | **bop** — jumps and runs off         |
| Drag the cat        | move it anywhere                     |

It always stays on top of other windows.
